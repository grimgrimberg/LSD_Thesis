# Missing Code - Contact Templates

Polite email templates for requesting unavailable or unclear prior-art code.
Do not send these automatically.

## Generic Template

```text
Subject: Code availability for [Paper Title]

Dear [Author Name],

I am writing regarding your publication "[Paper Title]" ([Journal, Year]).
I am a master's student building a reproducibility landscape for analyses using
the OpenNeuro ds003059 dataset.

Your work on [brief method description] is directly relevant to a thesis
project on transparent macro-dynamic mechanism ranking. I could not find a
public repository for the analysis scripts.

Would it be possible to share the analysis code or any runnable scripts used in
the study? I would be happy to cite your work and code appropriately, document
any wrapper scripts I create, and respect any usage restrictions you specify.

If the code cannot be shared, even methodological details about preprocessing,
inputs, model parameters, and statistical tests would help avoid
misrepresenting your analysis.

Thank you for your time.

Best regards,
[Your Name]
[Your Institution]
[Your Email]
```

## DLPFC / Ego Dissolution / Emotional Arousal - Granger Causality

```text
Subject: Code request - Granger causality analysis of DLPFC and ego dissolution under LSD

Dear Dr. Coleman,

I am writing regarding your research on theta-band thalamus-to-DLPFC
information flow and its relationship to ego dissolution and emotional arousal
under LSD. The review I am working from indicates that analysis code was
available from the lead author by email.

I am building a reproducibility landscape for the OpenNeuro ds003059 dataset as
part of my master's thesis. The thesis develops a transparent macro-dynamic
mechanism-ranking framework, and your Granger-causality analysis provides a
distinct fMRI/MEG perspective that complements the connectivity and
control-theoretic analyses in the landscape.

Would it be possible to share the analysis scripts, especially:

- Granger-causality estimation code
- fMRI/MEG fusion preprocessing steps
- Model-order, stationarity, and statistical-test choices
- Ego-dissolution and emotional-arousal correlation pipeline

I am happy to cite your contribution, document any reproduction notes clearly,
and respect any usage or redistribution conditions.

Thank you very much for your time.

Best regards,
[Your Name]
[Your Institution]
[Your Email]

Contact noted in review: clayton.r.coleman@gmail.com
```

## Notes

- Do not send emails automatically.
- Re-check public code availability before contacting authors.
- Ask for usage and redistribution terms before adding shared code to this
  repository.
- If code is not shared, document an independent reimplementation plan and mark
  it clearly.
