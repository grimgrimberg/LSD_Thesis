# Ising Temperature and Algorithmic Complexity

## Scope

Reproduce or adapt the Ruffini et al. Ising-temperature and algorithmic
complexity workflow for ds003059-derived BOLD time series.

## Verified Code Sources

| Source | Local path | Commit | Status |
|---|---|---:|---|

Verified repository facts:

- The Ruffini README says the notebook expects `data/lsd/LSD_all.npy`,
  `data/lsd/LSD_all.mat`, and `data/supp_data/AAL.pkl`.
- The notebook `Tutorial_LSD_two_conditions.ipynb` binarizes LSD/placebo time
  series and estimates personalized Ising temperatures.
- `neurotwin/applications/smith/utils.py` defines the BOLD binarization helper.
- `neurotwin/applications/smith/inet.py` implements temperature sweeps and
  Metropolis simulation logic.
- `StarLZW` provides Python LZW compression demos and library code.

## Data Requirements

- ds003059-derived ROI time series, not raw BIDS directly.
- AAL or equivalent parcellation metadata matching the expected array order.
- A declared binarization rule, typically median thresholding in the notebook.

## Dry-Run Check

```powershell
uv run python prior_art/scripts/dry_run_analysis_inputs.py ising_temperature_and_algorithmic_complexity
```

## Reproduction Path

1. Confirm legal access to required ds003059 derivatives or regenerate them
   from local BIDS data.
2. Build a converter from this repo's cached Stage 2 time-series artifacts to
   the notebook's `data/lsd/` format.
3. Run a small subject subset first and record binarization, random seed,
   parcellation, and temperature-grid choices.
4. Compare LSD/placebo personalized temperatures and LZW complexity only as
   macro-dynamic proxy outputs.

## Expected Outputs

- Subject-level Ising temperature estimates.
- LSD/placebo contrast of temperature estimates.
- LZW or related compression/complexity values.
- Notebook figures and summary tables.

## Connection to the Surrogate Model

Maps primarily to Layer A (transition-state proxy) and Layer D (dynamic
repertoire). The Ising-temperature and LZW outputs are useful comparators for
macro-dynamic disorder and state switching, but they do not validate biological
receptor mechanisms.
