# PI Package Static Site

Open `index.html` in a browser to view the offline landing page.

The page uses only relative links and local package assets. It does not use external CSS, JavaScript, CDNs, network calls, or a local server.

To upload manually, keep these paths together:

- `site/`
- `assets/`
- the package Markdown files in the parent folder

Do not treat the static page as a public scientific release until the PI approves the framing.
