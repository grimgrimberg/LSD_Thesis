A-E quick map

What the five letters mean

A: transition-state proxy

Tests whether the modeled system moves between coarse macro-states more easily under the LSD-like condition.

B: DMDc negative-control baseline

Uses a simple controlled-dynamics predictor as a baseline; currently kept visible as a negative or sanity check.

C: hierarchy/routing proxy

Tests whether sensory, associative, transmodal, and thalamic-gateway routing changes best match the cached target summaries.

D: dynamic-repertoire proxy

Tests whether the system explores a broader or different repertoire of network states and integration patterns.

E: lower transition/control-energy proxy

Asks how much model input energy is needed to move from placebo-like to LSD-like states; receptor-specific placement remains blocked.

How LSD was translated into graph theory and control theory. The empirical side is cached LSD-minus-placebo proxy targets from ds003059. The graph-theory side turns brain regions/modules into nodes and weighted relationships into edges, then asks which graph-modulated surrogate dynamics reproduce the target direction best. The control-theory side asks how hard it is, in that transparent surrogate, to move from a placebo-like state to an LSD-like state under candidate inputs. This is a model-fitting and mechanism-proxy ranking exercise, not a claim that LSD itself is literally a graph-control system.
