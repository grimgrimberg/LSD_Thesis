A-E Math And Metadata Guide

What A, B, C, D, and E mean, how the scoring story fits together, and which metadata files keep each claim grounded.

One-sentence version. The project compares five families of model-level macro-dynamic proxies against paired LSD/placebo summary evidence, ranks them by existing support scores, stress-tests the ranking, and then records what can and cannot be claimed.

Data layer

Cached paired LSD/placebo summaries for run-01 and run-03 provide group deltas and subject/run evidence. Run-02/music stays gated.

Model layer

The transparent 8-module surrogate creates interpretable macro-dynamic features rather than receptor-level biological parameters.

Claim layer

Scores, robustness, verdicts, and gate tables say which statements are supported, mixed, blocked, negative, or future.

Rubber duck

Say this out loud

"I am not saying the model experiences anything or proves receptor biology. I am asking which transparent proxy family best tracks the paired LSD/placebo macro-dynamic changes that are already summarized in the repo. A through E are five candidate explanations. Each one converts the same evidence into a different kind of measurable signature, then the package ranks those signatures and keeps the caveats visible."

The five letters

What A-E are actually testing

A - Transition-state proxy

Plain English: Does the system move between macro-states in a way that looks easier, more variable, or less stuck under LSD than placebo?

Math idea: count state occupancy, transition rate, transition entropy, dwell/barrier proxies, and trajectory step distances.

transition_rate = state_changes / possible_changes
H_transition = -sum p(i,j) * log(p(i,j))

Current read: implemented first-pass proxy, rank 4, score 0.148906. Useful, but not the provisional leading current layer pending motion/confound proof.

B - DMDc predictive baseline

Plain English: Can a simple controlled-dynamics predictor explain one-step changes better when condition information is included?

Math idea: fit a one-step linear dynamics model and evaluate leave-one-subject-out prediction error.

x_next ~= A x + B u
support ~= placebo_error - LSD_condition_error

Current read: negative/sanity baseline, rank 5, score -0.074064. It is kept because negative evidence prevents cherry-picking.

C - Hierarchy/routing layer

Plain English: Do the LSD/placebo differences look most like changes in how information routes across sensory, associative, transmodal, and thalamic-gateway structure?

Math idea: aggregate directional contrasts across hierarchy/routing features such as sensory-transmodal coupling, associative communication, thalamic coupling, and hierarchy-related compression.

C_score = aggregate signed support across hierarchy/routing metrics
stronger support = larger aligned LSD-minus-placebo deltas

Current read: provisional leading current proxy pending motion/confound proof, rank 1, score 0.332606; bootstrap rank-1 fraction 0.601562. Still a macro-dynamic proxy, not biological proof.

D - Dynamic repertoire layer

Plain English: Does the system explore a broader or different repertoire of network configurations?

Math idea: use dynamic-FC and graph-style summaries such as integration, segregation, modularity, participation, variance, and trajectory movement.

repertoire_support = aggregate graph/dynamic-FC feature shifts
examples: variance, participation, modularity, step distance

Current read: implemented first-pass proxy, rank 3, score 0.150619. It supports the story, but less strongly than C.

E - Control-energy proxy

Plain English: If the placebo-like macro-state is a starting point and the LSD-like macro-state is a target, which prior makes that transition cheaper in a simple control-energy sense?

Math idea: finite-horizon linear control energy compares candidate control profiles on a coarse macro graph.

x_next = A x + B u
energy = sum of squared L2 control-input norms over a finite horizon
lower energy = easier model-level transition under that control profile

Current read: rank 2, score 0.271724. It supports a lower transition/control-energy proxy, but receptor-specific placement is not supported; receptor-vs-random energy reduction is -1.844%.

The ranking result

Current order: C, E, D, A, B.

Interpretation: hierarchy/routing is the provisional leading macro-dynamic proxy under cached evidence, pending motion/confound proof. Control-energy is useful but split. D and A add supporting context. B is a negative predictive baseline.

What not to say: do not say this proves an LSD receptor mechanism, simulates subjective experience, or finishes the thesis.

How it comes together

The evidence pipeline

  1. Start with cached paired summaries. The package uses existing run-01/run-03 LSD-minus-placebo summaries. This is where subject count, run labels, and group deltas come from.
  2. Convert evidence into interpretable feature families. A-E are not arbitrary labels; each is a different family of measurable macro-dynamic features.
  3. Score each family. Existing artifacts aggregate signed feature support into a support score for each layer.
  4. Stress-test the ranking. Bootstrap and run-sensitivity artifacts ask whether the ordering survives subject resampling and run splits.
  5. Gate the claims. Claim verdicts and thesis gates keep supported, mixed, blocked, future, and negative claims separate.
  6. Present the proposed next track. The next milestone is not "is this finished?" It is the FD/DVARS/censoring motion-proof pack that must be solved before claim promotion.

PI prep

Rubber-duck checklist

If asked "what is C?"

"C is the hierarchy/routing proxy. It asks whether the paired LSD/placebo summary shifts look most like changes in sensory-associative-transmodal and thalamic-gateway routing. It is top-ranked now, but still needs motion and null checks before thesis-level promotion."

If asked "what is E?"

"E is a control-energy proxy on a coarse macro graph. It is useful for lower transition/control-energy interpretation, but the receptor-specific placement claim is not supported by the current evidence."

If asked "what is the math?"

"Each layer turns the same paired summaries into a family of numeric features, aggregates signed support into a score, then the robustness artifacts test whether the score is stable across resampling and run splits."

If asked "what proves this?"

"The metadata does not prove a biological mechanism. It proves that the package has a transparent evidence trail: source artifact, derived table, score, caveat, robustness check, and next action."
