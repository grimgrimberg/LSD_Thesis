LSD Thesis Evidence Workbench

A claim-gated macro-dynamic mechanism-ranking project that combines AI, control-theoretic priors, fMRI summary data, and a static evidence dashboard.

Open Evidence Open Figure Atlas

The problem

The hard part is separating a real macro-dynamic signal from attractive overclaims.

Data risk

Motion, session structure, preprocessing, music/run context, and artifact boundaries can mimic or distort dynamic effects.

Claim risk

Receptor, subjective, clinical, and biological-ground-truth language is tempting but unsupported unless stricter gates pass.

Review risk

A supervisor needs a fast way to inspect evidence, assumptions, missing controls, and next decisions without running the repo.

What I built

A transparent workbench, not just a result screenshot.

Surrogate model

8 coarse macro modules, stochastic graph-modulated dynamics, transition/barrier proxies, and perturbation summaries.

Empirical anchor

Cached paired LSD/placebo ds003059 run-01/run-03 summaries with subject/run caveats and local-only detail inspection.

Evidence dashboard

FastAPI/Jinja/Plotly locally, static GitHub Pages publicly, with artifact allowlists and payload contract tests.

Units and interpretation

The site tells the reader what each plot unit means before they interpret it.

Support score

Unitless proxy score for A-E ranking.

Rank-1 fraction

0-1 bootstrap proportion.

LSD - placebo delta

Metric-native paired difference.

FC delta

Correlation-unit difference.

Energy reduction

Percent network-control proxy reduction.

TR / horizon

TR count or model-step parameter.

What remains blocked

The project is stronger because it says what is missing.

Motion proof

FD/DVARS/censoring proof remains the main thesis blocker.

Archive DOI

GitHub release metadata is not the same as a verified Zenodo DOI.

Claim promotion

Receptor, PET, SC, neuromaps, run-02/music, and subjective claims remain gated.
