Method scope

Methods And Limitations

The methods support supervised review of a macro-dynamic proxy workbench. They do not complete a neuroscience thesis or promote receptor, subjective, or clinical claims.

A-E proxy families

A is a transition-state proxy, B is a DMDc negative-control baseline, C is a hierarchy/routing proxy, D is a dynamic-repertoire proxy, and E is a lower transition/control-energy proxy. The current ranking compares these proxy families against the same cached LSD-minus-placebo target summaries; it does not turn any one family into biological ground truth.

How graph theory enters

The workbench represents the coarse system as a graph: macro modules are nodes, relationships are weighted edges, and graph-derived summaries describe routing, integration, segregation, hierarchy, and repertoire changes. This gives a transparent mathematical object to compare with the empirical proxy targets.

How control theory enters

Control theory is used as a question about transitions in the surrogate graph: how much input energy is required to move from a placebo-like model state toward an LSD-like model state under a candidate prior. This supports E as a lower transition/control-energy proxy, not receptor-specific proof.

What was fitted

The quantitative fit is between model-level proxy outputs and cached ds003059 LSD-minus-placebo summary targets. The interpretation layer asks which proxy family best explains that fit while preserving negative baselines, blocked motion/confound gates, and unsupported receptor claims.

What decisions the methods can support

Whether the current C-led proxy ranking is worth developing through a motion-proof-first thesis plan, and which blocked gates should be closed before stronger language is used.

Implemented pipeline

Typed Python package, 8-module stochastic graph surrogate, cached paired ds003059 summaries, A-E mechanism-proxy ranking, robustness views, static publication build, and artifact allowlists.

Current proxy limitations

Outputs are model-level proxies. Switching barriers, integration metrics, control energy, and rank scores are not biological ground truth.

Missing thesis-grade analyses

Subject-level FD/DVARS/censoring motion-confound proof, verified DOI/archive publication, atlas/parcellation replication, and cross-dataset stress-test evidence remain unresolved gates.

Future methods

After the motion gate, add parcellation/null sensitivity, cross-dataset stress-test audit, and strictly separated receptor/PET/SC/neuromaps checks if the user and supervisor approve scope.

Methods page is a boundary map for PI review, not a claim-promotion document.
