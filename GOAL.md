# Goal

Transform this repository from a fragile mixed research prototype into a rigorous, explainable, reproducible thesis/research prototype for altered-state-inspired macro brain dynamics.

## Success Criteria

- Preserve a Git safety baseline and phase commits for rollback.
- Keep the project framed as a transparent surrogate model, not a receptor model, clinical model, or subjective-experience simulator.
- Make the existing pipeline inspectable: graph config, simulator, ds003059 extraction, fitting, perturbation ranking, ablations, dashboard, and publication outputs.
- Document how to install, test, run, reproduce, and interpret results.
- Strengthen safety, tests, command documentation, and research honesty before any major model rewrite.

## Evidence Taxonomy

- Implemented: present in code and covered by tests or generated artifacts.
- Present but broken: present in code or docs but failing, unreliable, or incomplete.
- Described only: documented but not implemented.
- Inferred: likely from repo context, not directly stated.
- Proposed: recommended next work.
- Speculative: plausible research direction without current evidence.
- Out of scope: explicitly not part of the current prototype.
