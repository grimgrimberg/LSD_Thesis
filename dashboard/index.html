Interactive evidence surface

Show the gate before the claim.

This project tests whether LSD-like empirical macro-dynamics are better explained by altered transition/control dynamics than by generic noise, motion, or static connectivity changes.

Conservative framing

The receptor, myelin, gradient, and structural-connectome panels are exploratory priors until stronger spatial-null and external-validation gates pass.

GitHub Pages is static: it can show the pitch, claim gates, and derived artifacts, but it cannot run simulations or subject-level API calls.
